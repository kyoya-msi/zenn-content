デバウンス処理を回路に組み込みしようとした際にシンクロナイザ回路とエッジ検出回路が混同してしまっていることに気づき、全体を見直しました。  
自分の中では、シンクロナイザ回路を「なんとなくノイズ信号除去してくれる～」くらいの感覚で捉えていて、エッジ検出回路との役割の境界が曖昧なままでした。  
そのため、最初は「デバウンスもDFF1段目と2段目、それぞれにかければいいのでは？」と考えていたんですが、それだと2つの回路の目的を混同していることになります。  
改めて整理すると、それぞれの役割は以下のように別物でした。  

| 回路 | 役割 |
| :-- | :-- |
| シンクロナイザ回路 | クロックと無関係なタイミングで変化する非同期信号を、2段DFFでクロック同期信号に変換する（メタステーブル対策） |
| デバウンス回路 | 同期化された信号に残っているチャタリングを除去する |
| エッジ検出回路 | 安定した信号の変化点（立ち上がり）を検出する |

つまり、デバウンスをかけたいのは「同期化された後の信号」ということです。  
また、デバウンス回路の出力はあくまで「ばたつきを取り除いた安定信号」であって、それ自体はまだ変化点(エッジ)の情報を持っていません。そのため、デバウンス回路の後段に改めてエッジ検出回路を組み直す必要がある、という結論になりました。  
この整理をしたことで、上記の全体回路図にたどり着いた、という流れです。

### デバウンス回路
デバウンス回路は、[チャタリング](https://ja.wikipedia.org/wiki/%E3%83%81%E3%83%A3%E3%82%BF%E3%83%AA%E3%83%B3%E3%82%B0)による誤判定を防ぐために「入力が一定時間(20ms)安定して変化しなかった場合のみ、その値を正式な出力として採用する」という考え方で設計しました。  
20msという数値については、Basys3のボタン(BTNC)を実際にILAで実測しようとしたのですが、ロジックアナライザの内容が簡易動作確認の範囲を大きく超える工数がかかりそうだったので、今回は一般的な指標値としてよく参照される[Ganssleの実測研究の値](https://www.ganssle.com/missing.html)に安全マージンを取った値を採用することにしました。(AIの提案ですね～)  
Basys3のクロック周波数は100MHz([リファレンス](https://digilent.com/reference/programmable-logic/basys-3/reference-manual?__cf_chl_f_tk=wvpqWyOFr7m4XB.h3723Q84bt6W3fVXZdaTS0lSIAyg-1783162171-1.0.1.1-YbszgDjZNvwoUozs4r9E_ztQyjoPiqgpYKnMtJbgCJc))のため、クロック周期は10nsです。  
20ms(2,000,000ns)をカウントするには最低でも2,000,000カウント必要で、カウンタのビット幅は21bitとしています。  
動作としては、入力信号が変化するたびにカウンタをリセットし、変化がないままカウンタが21bit分カウントアップし切ったタイミングで初めて出力を更新する、という仕組みを考えています。

### モジュール分割
ここまでの内容を踏まえ以下のようにモジュール分割を行いました。  

| 回路名 | モジュール名 | 処理内容 |
| :-- | :-- | :-- |
| 全体回路 | top | BTNCからLED7出力までの全体の信号の流れを配線する |
| シンクロナイザ回路 | synchronizer | 非同期データを同期データに変換する |
| デバウンス回路 | debounce | バウンスデータを除去する |
| エッジ検出回路 | edge_detector | ボタン押下を検出する |
| ロジック回路 | toggle_logic | ボタン押下によるLED状態変化を行う |

### 積み残し
今回整理しきれなかった点として、以下が残っており、本格的にCPU設計していくときに頑張ろうと思っています。  
* MTBF(平均故障間隔)の計算(シンクロナイザ回路)
* バウンス時間の実測(デバウンス回路)

## まとめ
今回の内容をまとめると以下になります。  
* デバウンス回路を組み込む過程で、シンクロナイザ回路とエッジ検出回路の役割を混同していたことに気づき、全体設計を見直した
* シンクロナイザ回路は非同期→同期変換、デバウンス回路はチャタリング除去、エッジ検出回路は変化点の検出、と役割を切り分けて整理した
* デバウンス回路は、Ganssleの経験則(20ms)をもとに21bitカウンタで設計した
* シンクロナイザ／デバウンス／エッジ検出／ロジックの4モジュールに分割した全体回路図を確定した
